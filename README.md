# AI情报官 · 对公授信前置尽调（陌拜情报官）

银行对公客户经理的「陌拜情报官」——授信前置尽调专用 AI 技能。输入企业名称，输出一页式标准化情报包，同时具备**营销切入线索**与**信贷风险排查**双重价值。

## 功能

基于国家企业信用信息公示系统、天眼查/企查查/爱企查、裁判文书网、执行信息公开网、政府采购/招投标平台、环评公示、行业媒体等**公开数据全量检索**，输出七模块情报包：

| 模块 | 内容 |
|---|---|
| 一、核心名片 | 工商底档关键信息（资质/股权/人员/抵押/历史沿革） |
| 二、全景风险扫描 | 8 大风险子模块 + 风险等级 + ⚠️ 授信准入一票否决项 |
| 三、业务触发敲门点 | 2-3 条绑定公开事实的具象话术理由 |
| 四、产业链上下游 | 供应商/客户/供应链金融可贷场景/供应链风险 |
| 五、实控人 & 高管穿透 | 持股架构/关联企业/个人风险/人脉价值 |
| 六、陌拜实操策略 | 开场话术/分层递进/现场核实问题清单 |
| 七、可贷业务清单 | 产品适配判断 + 额度参考 + 风控核实要点 |

## 安装

将 `ai-intel-officer/` 文件夹完整放入技能的根目录（例如 `workspace/.user_skills/`），保持目录结构：

```
workspace/.user_skills/ai-intel-officer/
├── SKILL.md
└── references/
    ├── due-diligence-workflow.md   # 检索与提取全指令（五大部分）
    ├── output-template.md          # 标准化输出模板（七模块）
    └── source-guide.md             # 数据源映射指南
```

## 使用示例

- 「查一下 XX 公司的陌拜情报」
- 「XX 公司授信尽调」
- 「帮我做 XX 公司的背景调查」
- 「XX 公司能不能授信」

## 合规声明

本技能仅使用公开渠道信息，不编造任何数据；情报包仅供合法信贷尽职调查与业务拓客使用，不得用于骚扰、敲诈或任何违法用途。实控人/高管个人信息仅取公开的工商、司法、公示、媒体报道信息。
