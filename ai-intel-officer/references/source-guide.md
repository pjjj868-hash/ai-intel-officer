# 数据源映射指南

> 每个信息模块对应的公开渠道、检索技巧与局限性。检索受阻时查阅本文件换源。

## 官方权威源（优先级最高，可直接精读）

| 数据源 | 覆盖模块 | 检索技巧与局限 |
|---|---|---|
| 国家企业信用信息公示系统（gsxt.gov.cn） | 基础底档、经营异常、行政处罚 | 权威底档；页面反爬强，可能需多次尝试或走搜索引擎快照；最终口径以此为准 |
| 信用中国（creditchina.gov.cn） | 行政处罚、失信、红黑名单 | 行政处罚与失信名单权威来源 |
| 中国裁判文书网（wenshu.court.gov.cn） | 司法涉诉、裁判文书 | 检索接口不稳定，先试搜索引擎 `site:wenshu.court.gov.cn {企业名}` |
| 中国执行信息公开网（zxgk.court.gov.cn） | 被执行、失信、限高、终本 | 验证码/反爬常见；用搜索引擎检索 `{企业名} 被执行人` 作为补充 |
| 中国政府采购网（ccgp.gov.cn） | 中标、集采入围 | 站点搜索可用；注意公告滞后 |
| 各地公共资源交易中心 | 中标、招标 | 按企业所在地搜索；金额信息较全 |
| 全国排污许可证管理信息平台 | 排污许可、环评 | 企业名+排污许可检索 |
| 生态环境部/省厅环评公示 | 环评批复 | 检索 `{企业名} 环评 公示` |
| 国家知识产权局（专利检索） | 专利、软著 | 专利检索系统可用 |
| 商标局（sbj.cnipa.gov.cn） | 商标 | 商标查询系统可用 |
| 海关（进出口/高级认证） | 进出口增量、AEO | 公开披露有限，多靠新闻与公示 |

## 商业聚合平台（摘要可用，明细页常需登录付费）

| 数据源 | 覆盖模块 | 使用原则 |
|---|---|---|
| 天眼查 / 企查查 / 爱企查 | 全模块聚合：股权、变更、对外投资、涉诉、质押 | 用搜索引擎检索 `{企业名} 天眼查` / `{企业名} 企查查` 获取摘要页内容；明细页需会员时标记「待线下核实」，不编造 |
| 启信宝、水滴信用 | 聚合补充 | 同上 |

| 数据源 | 覆盖模块 | 说明 |
|---|---|---|
| 全国法院被执行人信息查询 | 被执行 | 官方；反爬时走搜索补充 |
| 各地法院官网开庭公告 | 开庭公告 | 检索 `{企业名} 开庭公告` |
| 政府采购严重违法失信名单 | 招投标违规 | 检索 `{企业名} 政府采购 违法` |
| 应急管理部/安全生产公示 | 安全生产处罚 | 检索 `{企业名} 安全生产 处罚` |
| 税务部门重大税收违法案件公布 | 税务稽查 | 检索 `{企业名} 税收违法` |

## 经营与产业信息

| 数据源 | 覆盖模块 | 说明 |
|---|---|---|
| 行业媒体、地方新闻 | 动态信号、舆情、人脉 | 检索 `{企业名} 新闻` / `{企业名} 签约` |
| 招聘平台（社保/规模线索） | 资金运营、参保人数 | 招聘活跃度与规模是经营温度信号 |
| 企业官网/公众号 | 产品、客户、新闻 | 直接 fetch；注意官网信息可能滞后或美化 |
| 年报/信用报告（如披露） | 营收、客户集中度 | 上市公司/发债主体可查公开年报；非上市中小企业多靠公开信息推断 |
| 行业协会公示 | 黑名单、任职 | 检索 `{行业}协会 {企业名}` |

## 换源策略
1. 官方源打不开/反爬 → 用 `general_search` 检索该源域名下的快照（`site:` 语法）。
2. 商业平台明细需付费 → 保留摘要，字段标「待线下核实」。
3. 中文源无结果 → 尝试英文/拼音检索、企业曾用名检索。
4. 单条信息多渠道交叉验证后写入情报包，仅单一来源的信息标注来源并提示。
