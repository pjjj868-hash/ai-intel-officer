# 标准化输出模板（一页式陌拜尽调提纲）

> 汇总输出时**必须**按本模板七模块组织。目标：客户经理拿到即可直接用于陌拜与授信准入判断，不铺陈检索过程。

---

## 输出总结构（七模块，顺序固定）

```
# {企业名称} 陌拜尽调情报包（{检索日期}）
## 一、核心名片（工商底档关键信息）
## 二、全景风险扫描（正面资质 + 全部负面风险 + 风险等级 + 一票否决项）
## 三、🔥 业务触发敲门点（2-3 条具象话术理由）
## 四、产业链上下游深度分析
## 五、实控人 & 高管穿透分析
## 六、陌拜实操策略
## 七、可贷业务清单
（附：信息来源与待核实事项）
```

## 模块二：全景风险扫描

### 正面资质清单
分模块罗列：荣誉资质、准入证书、知识产权、中标业绩、补贴获得、纳税等级等（与模块一互补，突出可营销的正面资产）。

### 负面风险清单（分模块 + 风险等级标注）

| 风险类别 | 风险描述 | 关键事实（金额/案号/文号/日期） | 风险等级 |
|---|---|---|---|
| 司法涉诉 | | | 低/中/高 |
| 执行失信 | | | 低/中/高 |
| 行政监管 | | | 低/中/高 |
| 或有负债（担保） | | | 低/中/高 |
| 舆情负面 | | | 低/中/高 |
| 实控人个人风险 | | | 低/中/高 |
| 资金运营 | | | 低/中/高 |
| 行业政策 | | | 低/中/高 |

### 风险等级标注规则
- **低风险**：无负面记录或仅有轻微、已了结、与经营关联弱的事项。
- **中风险**：存在未决诉讼/被执行（金额小）、行政罚款已整改、或有担保金额可控、行业景气下行等单一或多项叠加。
- **高风险**：失信被执行、大额未履行被执行、终本案件、限高、重大处罚、实控人重大负面、经营异常未移出等。
- 等级判定给出**一句理由**；多类中风险叠加时按高风险提示。

### ⚠️ 授信准入一票否决项提示（命中即醒目标注）
1. 失信被执行人（企业或实控人）未履行完毕。
2. 大额被执行 / 终本案件 / 限制高消费且无合理解释与化解方案。
3. 重大行政处罚（环保、安全、税务）未整改或涉刑。
4. 列入经营异常名录且长期未移出 / 年报失联。
5. 实控人重大负面（涉刑、民间借贷重大纠纷、多笔大额担保代偿）。
6. 企业已停产停业、吊销、注销或在清算。
> 未命中以上项时明确写「**未发现一票否决项**」，并提示最终以征信报告、实地下户核实为准。

## 模块三：🔥 业务触发敲门点（2-3 条具象话术理由）

每条敲门点**必须绑定公开可查事实**（项目/中标/技改/补贴/扩产），格式：

```
敲门点 1：{一句话理由}
- 绑定事实：{项目名/中标金额/时间/来源}
- 切入话术：「{可直接对客户说的话，20-40字，含利益点}」
```

示例话术逻辑：不推销产品，先给情报价值（「看到贵司 X 项目公示，正好我这边有配套资金方案…」）。

## 模块四：产业链上下游深度分析

- **上游采购风险**：核心原材料/设备、供应商集中度、结算模式（预付/赊购）、关联供应商提示。
- **下游回款优势**：客户结构、央企/国企大客户、账期、应收账款规模与质量。
- **供应链金融可贷场景**：应收款融资、订单贷、仓单质押、保兑仓、票据贴现的适配判断（写明理由与前提条件）。

---

## 模块五：实控人 & 高管穿透分析

| 维度 | 内容 |
|---|---|
| 持股架构 | 直接持股 → 穿透至实控人（含一致行动/代持公开线索） |
| 个人资产线索 | 公开可查的对外投资、持股企业（不推测隐私） |
| 关联企业 | 实控人/高管名下及任职的其他企业 |
| 个人风险 | 被执行、失信、股权质押、担保、涉诉（公开记录） |
| 人脉价值 | 行业协会/商会/社会身份、公开报道的政企交集、校友/同业关系 |

## 模块六：陌拜实操策略

- **开场话术逻辑**：前 30 秒价值锚定（情报价值 → 专业背书 → 需求探测），示例话术 1-2 条。
- **分层递进沟通顺序**：先谈企业（经营/扩产）→ 再谈行业（政策/趋势）→ 后谈资金（需求/方案），每层给 1-2 个问题。
- **现场必须核实的经营/财务/风控关键问题清单**（10 条以内，直指授信核心）：
  1. 实缴资本与出资到位情况？
  2. 近两年营收、利润、纳税实绩（与公开信息比对）？
  3. 主要客户账期与应收账款回收情况？
  4. 前五大客户/供应商集中度？
  5. 现有银行授信额度、使用率、担保方式？
  6. 对外担保/互保情况？
  7. 抵押物产权与评估价值？
  8. 用工与社保实缴人数？
  9. 近期扩产/技改资金来源与进度？
  10. 涉诉/被执行事项的现状与化解安排？

## 模块七：可贷业务清单（一页纸模板）

| 产品类别 | 适配判断（结合情报） | 额度/期限参考 | 风控核实要点 |
|---|---|---|---|
| 流动资金贷 | | | 营收真实性、纳税报表、回款账户流水 |
| 固定资产贷 | | | 项目批复/环评/土地权证、自筹资金比例 |
| 技改贷（设备更新） | | | 技改备案、设备采购合同、投产预期 |
| 应收保理（应收账款融资） | | | 核心买方确权、账期与历史回款、集中度 |
| 票据（承兑/贴现） | | | 贸易背景真实性、上下游票据流转 |
| 设备抵押 | | | 设备权属、评估价值、变现能力 |
| 供应链批量授信 | | | 核心企业信用、链上企业关联、闭环管控 |

每行给出「适配判断」一句话结论；不适用产品写明原因（如无固定资产、下游分散难以确权）。

## 附：信息来源与待核实事项

- 按模块列出主要来源（官方公示/裁判文书/执行信息/招投标/媒体等），重要事实附 URL。
- 列出全部「待线下核实」字段与原因（封闭数据、渠道覆盖不到、信息冲突）。
- 末尾固定提示：「本情报包基于公开信息整理，仅供授信尽调参考，最终以征信报告、实地调查、财务审计为准。」
