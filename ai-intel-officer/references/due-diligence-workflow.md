# 检索与提取全指令（五大部分）

> 本文件是技能执行的核心指令。对目标企业逐模块检索，字段级核对，历史变更同步标注。
> 检索以 `general_search` 多关键词并行推进，关键原文用 `web_fetch` 精读。命中数据必须记录来源。

---

## 一、基础底档（必填 · 工商主体穿透）

检索并完整提取以下信息，**同步标注历史变更记录**（变更前后、变更日期）：

### 1.1 主体资质
| 字段 | 说明 |
|---|---|
| 统一社会信用代码 | 唯一标识，用于消歧与后续核验 |
| 成立日期 / 登记状态 | 存续 / 在业 / 吊销 / 注销 |
| 经营地址 | 注册地址 + 实际经营地址（如可获） |
| 主营业务 / 经营范围 | 当前范围 + 历史变更 |
| 曾用名 | 如有 |
| 行业分类 | 国民经济行业分类代码与名称 |
| 纳税信用等级 | A/B/C/D/M 级及评定年份 |
| 荣誉资质 | 高新技术企业、专精特新、企业技术中心、瞪羚/独角兽等 |
| 行业准入证书 | 生产许可、特种设备制造许可、环评批复、排污许可、食品/药品/危化品经营许可等 |
| 知识产权 | 专利（发明/实用新型/外观）、商标、软著数量与核心专利名称 |

**检索关键词示例**：`{企业名} 统一社会信用代码`、`{企业名} 经营范围 注册资本`、`{企业名} 高新技术企业`、`{企业名} 专利 商标`、`{企业名} 排污许可 环评`、`{企业名} 纳税信用等级`。

### 1.2 资本股权
- 注册资本、**实缴资本**、认缴期限（实缴与认缴差额是出资风险点）。
- 历次股权变更记录（时间、转让方、受让方、比例、金额）。
- 股权结构：直接股东（自然人/法人）及持股比例。
- 穿透后实际控制人（层层穿透至自然人/国资主体）。
- 关联对外投资企业、集团成员企业（子公司、分公司、参股公司清单）。

**检索关键词示例**：`{企业名} 股权结构`、`{企业名} 股东 实缴`、`{企业名} 对外投资`、`{企业名} 股权变更`、`{企业名} 实际控制人`。

### 1.3 人员架构
- 法定代表人、执行董事/总经理、监事、核心高管名单。
- 高管任职履历（公开可查部分）、对外任职关联企业（高管在外兼任情况）。

**检索关键词示例**：`{企业名} 法定代表人 高管`、`{人名} 任职 企业`。

### 1.4 资产抵押
- 动产抵押、不动产抵押、设备抵押、股权质押登记记录。
- 抵押担保债权金额、抵押权人（银行/融资租赁/担保公司等）。
- 抵押物是否为核心生产经营资产（影响第二还款来源判断）。

**检索关键词示例**：`{企业名} 动产抵押`、`{企业名} 股权质押`、`{企业名} 抵押 登记`。

### 1.5 历史沿革（完整时间线）
- 注册地址迁移、经营范围变更、增资减资、法人/股东更迭，按时间排列。
- 异常信号：短期内频繁变更法人/股东/地址、大幅减资、名称变更。

**检索关键词示例**：`{企业名} 变更记录`、`{企业名} 工商变更 历史`。

## 二、动态触发信号（必填 · 近 24 个月经营增量业务线索）

全网检索近 24 个月官方公示、招投标、政府公告、行业新闻，筛选经营增量动作，**标注项目时间、金额、规模**：

- 扩产技改、新建生产线、厂房扩建、产能升级
- 土地摘牌、环评批复、设备更新
- 大额中标、集采入围、央企/国企供应商入库
- 战略合作签约、大额订单公示
- 新增融资（股权融资/银行授信/发债）
- 政府产业补贴、专项资金
- 进出口增量备案、海关高级认证（AEO）

**检索关键词示例**：`{企业名} 中标`、`{企业名} 环评`、`{企业名} 招标 采购`、`{企业名} 技改 项目`、`{企业名} 补贴 专项资金`、`{企业名} 战略合作`、`{企业名} 供应商 入库`、`site:ccgp.gov.cn {企业名}`（政府采购网）、`{企业名} 2025 OR 2026 订单`。

> 每个信号都要成为陌拜「敲门点」候选：时间 + 金额 + 项目名三要素齐全才可作为话术事实。

## 三、产业链上下游（必填 · 供应链金融挖掘 + 供应链风险排查）

### 3.1 上游供应商
- 核心原材料、生产设备供应商清单（公开可查部分）。
- 单一大供应商采购占比（如披露）；结算周期；是否存在关联供应商（与股东/高管有关联的供应商）。
- 采购模式：预付 / 赊购 / 现款。

### 3.2 下游客户
- 终端采购方类型（能源、化工、供热、城投、零售、品牌商等）。
- 央企/国企大客户名单（招投标公告、官网新闻、年报披露）。
- 前五大客户营收占比（如披露）；账期；应收账款规模。

### 3.3 供应链金融线索（可落地场景识别）
- 应收款融资（核心企业确权难度、账期匹配度）。
- 订单贷、仓单质押、保兑仓、票据贴现的适配判断。
- 上下游是否存在可批量授信的链上企业集群。

### 3.4 供应链风险点
- 上下游集中度风险（单客户/单供应商占比过高）。
- 客户逾期诉讼、供应商断供信号。
- 上下游涉诉连带风险（产业链某环节暴雷传导）。

**检索关键词示例**：`{企业名} 供应商`、`{企业名} 客户`、`{企业名} 应收账款`、`{企业名} 采购`、`{企业名} 供应链`、`{企业名} 中标 客户`。

## 四、全维度风险尽调（必填 · 授信前置风控核心，8 子模块）

### 4.1 司法涉诉风险
- 买卖合同纠纷、民间借贷、担保追偿、劳动仲裁、知识产权侵权、开庭公告。
- 裁判文书：案号、涉案金额、原告/被告身份（本企业是原告还是被告）、判决结果。

### 4.2 执行失信风险 ⚠️（一票否决高发区）
- 被执行记录、未履行金额、限制高消费、失信被执行人、终本案件。
- 股权冻结、账户冻结。

### 4.3 行政监管风险
- 环保处罚、安全生产处罚、税务稽查、市场监管罚款、土地违规、招投标违规。
- 行政处罚文号、处罚机关、处罚事由、处罚金额、整改情况。

### 4.4 或有负债风险
- 对外担保、互保联保、关联企业担保。
- 担保金额、担保到期日、被担保企业自身风险状况。

### 4.5 舆情负面风险
- 行业投诉、产品质量曝光、欠薪、债务传闻、媒体负面报道、行业协会黑名单。

### 4.6 实控人个人风险
- 股东/实控人个人被执行、失信、民间借贷、股权质押、个人担保、征信负面。
- 仅用公开司法/执行/公示信息，不做推测。

### 4.7 资金运营风险
- 年报营收波动、参保人数大幅增减（人员规模真实性信号）。
- 频繁变更银行账户、大额资金往来异常、经营地址异常、年报失联（列入经营异常名录）。

### 4.8 行业政策风险
- 所属行业限产、环保管控、产能过剩、下游行业周期波动（按目标企业实际所属行业调整，勿套用固定行业）。

**检索关键词示例**（每子模块独立检索）：
- 涉诉：`{企业名} 裁判文书`、`{企业名} 诉讼 纠纷`、`{企业名} 开庭公告`
- 执行：`{企业名} 被执行`、`{企业名} 失信`、`{企业名} 限制高消费`、`{企业名} 终本`
- 监管：`{企业名} 行政处罚`、`{企业名} 环保处罚`、`{企业名} 税务 处罚`、`{企业名} 经营异常`
- 担保：`{企业名} 对外担保`、`{企业名} 担保 公告`
- 舆情：`{企业名} 投诉`、`{企业名} 欠薪`、`{企业名} 负面 新闻`
- 实控人：`{实控人姓名} 被执行`、`{实控人姓名} 失信`、`{实控人姓名} 股权质押`
- 参保：`{企业名} 社保 参保人数`
- 行业：`{行业} 产能过剩 2025`、`{行业} 限产 环保政策`

## 五、人脉与舆情（加分项 · 信任破冰切入点）

- 实控人、董事长、总经理**公开履历**、行业协会任职、商会职务、人大/政协等社会身份。
- 本地政企人脉、上下游头部企业高管交集、校友圈层、同业龙头合作关系（仅公开报道可证实的）。
- 企业获奖、政府走访、产业扶持报道、行业峰会公开发言素材。

**检索关键词示例**：`{人名} 履历 董事长`、`{人名} 商会 协会`、`{人名} 人大代表`、`{企业名} 获奖`、`{企业名} 政府 调研`、`{企业名} 峰会 发言`。

## 检索兜底规则

1. 某字段多渠道均查不到 → 在输出中标注「**待线下核实**」，不得留空或编造。
2. 企业重名 → 用统一社会信用代码 / 地区 / 成立日期确认目标主体，输出中注明消歧依据。
3. 同源信息在不同平台不一致 → 并列展示并提示以官方公示渠道为准。
4. 检索结果为零 → 区分「确实无记录」与「渠道覆盖不到」，后者明确提示。
